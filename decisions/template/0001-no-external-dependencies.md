# 1. 외부 의존 없는 최소 템플릿

## 상태

채택(2026-09-26).

## 배경

이 저장소는 Xcode 와 git 만 있는 Mac 에서 바로 동작해야 합니다. 저장소 주인은 다른 도구를 설치하거나 설정하지 않고 에이전트에게 앱을 만들게 할 수 있어야 합니다. 외부 패키지나 별도 도구가 필요하면 첫 실행이 느려지고, 실패할 수 있는 곳이 늘어납니다.

## 결정

- 이 저장소는 Xcode(Swift 6.1 이상)와 git 만으로 동작합니다.
- 외부 SwiftPM 패키지에는 의존하지 않습니다. 저장소 도구 `repo` 도 명령줄 인자를 직접 해석합니다.
- lint 는 툴체인에 포함된 `swift format` 으로 합니다.
- 앱 틀도 외부 의존 없이 Core, GUI, CLI, 테스트를 갖춥니다.

## 검토한 대안

- **공용 라이브러리 묶음 위에 앱 틀을 만들기:** 기각되었습니다. 첫 실행에 네트워크와 빌드 시간, 설치 전제가 늘어나고, 쓰지 않는 코드가 저장소에 들어옵니다.
- **swift-argument-parser 같은 외부 패키지 쓰기:** 기각되었습니다. 첫 실행 때 패키지를 받느라 네트워크와 시간이 들고, 실패할 수 있는 곳이 늘어납니다.

## 결과

- Xcode 와 git 만 설치되어 있으면 `swift run repo doctor` 부터 실행할 수 있습니다.
- 인자 해석과 프로세스 실행 같은 기능은 저장소 도구 `repo` 가 직접 구현합니다.
- 앱에 외부 패키지가 필요하면 저장소 주인이 결정 기록과 함께 더합니다.
