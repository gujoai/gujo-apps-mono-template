# 1. 외부 의존 없는 최소 템플릿

## 상태

채택(2026-09-26).

## 배경

이 템플릿은 고객이 자기 GitHub 에 저장소를 만들고 자기 노트북에서 에이전트에게 앱을 만들게 하는 데 쓰입니다. 템플릿을 만든 쪽의 도구와 비밀, 내부 코드는 고객 환경에 없습니다. 기존에 쓰던 사내 앱 틀은 사내 전용 라이브러리 30여 개에 의존했기 때문에 고객 환경에서 그대로 쓸 수 없었습니다.

## 결정

- 템플릿은 Xcode(Swift 6.1 이상)와 git 만으로 동작하게 만듭니다.
- 외부 SwiftPM 패키지에는 의존하지 않습니다. 저장소 도구 `repo` 도 명령줄 인자를 직접 해석합니다.
- lint 는 툴체인에 포함된 `swift format` 으로 합니다.
- 앱 틀도 처음부터 새로 쓰고, 외부 의존 없이 Core, GUI, CLI, 테스트를 갖춥니다.

## 검토한 대안

- **사내 앱 틀에서 필요한 부분만 추려 쓰기:** 기각했습니다. 필요한 부분만 추려도 30여 개 라이브러리 가운데 상당수와 사내 정보가 함께 딸려 옵니다.
- **swift-argument-parser 같은 외부 패키지 쓰기:** 기각했습니다. 첫 실행 때 패키지를 받느라 네트워크와 시간이 들고, 고객 환경에서 실패할 수 있는 곳이 늘어납니다.

## 결과

- 고객은 Xcode 와 git 만 설치하면 `swift run repo doctor` 부터 실행할 수 있습니다.
- 인자 해석과 프로세스 실행 같은 기능은 이 저장소가 직접 유지해야 합니다.
- 앱에 외부 패키지가 필요하면 저장소 주인이 결정 기록과 함께 더합니다.
